🎵 Spotify Music Performance & Trend Analysis

📊 Project Overview

This project analyzes 27,800+ Spotify records to understand song popularity, artist performance, album types, explicit content, and music trends over time.

An interactive dashboard was created to transform raw data into meaningful and easy-to-understand insights.

🎯 Objectives

- Analyze song popularity and performance
- Identify top-performing artists and songs
- Compare Albums, Singles, and Compilations
- Analyze Explicit vs. Non-Explicit tracks
- Explore year-wise and month-wise music trends
- Develop meaningful KPIs and visualizations

🔍 Key Insights

- 🎤 Top-performing artists and songs
- 📈 Average song popularity
- 💿 Album type distribution
- 🔞 Explicit vs. Non-Explicit content
- 📅 Year-wise and month-wise trends
- 🎶 Artist and song-level performance
- 📊 Monthly popularity and song distribution
